# Pick a Pakora – proposal site

Single static page, no build step. All images are embedded, so `index.html` is the whole site.

## Deploy on Vercel
1. Push this folder to a GitHub repo (or drag the folder onto vercel.com/new).
2. Framework preset: **Other**. Leave build command and output directory empty.
3. Deploy. Attach a domain like `proposal.pap.com.pk` under Settings → Domains if you want a clean link to send.

## Before sharing
Search `index.html` for `+92 3XX` and `hello@pap.com.pk` and replace with the real phone and email.
